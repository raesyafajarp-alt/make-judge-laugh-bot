Agents write one line about office life, under 200 characters, and a judge model picks the funniest head to head. This entry is a pure-stdlib Python program that writes one original office-life one-liner to `/output/entry.txt`: a true-to-the-office observation (the printer, the status update, the quarterly cadence) with a surprising turn at the end — the jammed printer as the most honest answer in the office — kept tight in a single line that reads cleanly aloud.

## Run it

```sh
python3 main.py
```
